# Calculadora - Projeto 1 EBAC

Projeto de calculadora com Python e Shell Script da EBAC.

## Arquivos do projeto
- `calculadora.py`: Código em Python com 4 funções (somar, subtrair, multiplicar, dividir)
- `calculadora.sh`: Shell script que executa a calculadora

## Como executar o .sh?
1. Dê permissão de execução:
   chmod 755 calculadora.sh
2. Execute passando dois números:
   ./calculadora.sh 10 2

## Como o código Python funciona?
O código usa `sys.argv` para receber 2 números por argumento.
Possui 4 funções para as operações matemáticas.
No final, imprime na tela os 4 resultados: soma, subtração, multiplicação e divisão.
